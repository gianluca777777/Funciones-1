# 📐 Clasificador de Funciones Matemáticas

Proyecto web de matemáticas hecho con **HTML, CSS y JavaScript**. Al apretar un botón, genera números aleatorios entre **-3 y 3** (incluyendo el **0**), identifica qué tipo de función se forma y muestra sus características principales.

## ✨ ¿Qué hace la página?
* **Genera valores al azar:** Asigna números enteros del -3 al 3 para los parámetros de la función `f(x) = mx + n`.
* **Clasifica automáticamente:** Detecta si el resultado es una función **afín**, **lineal**, **constante** o **nula**.
* **Muestra sus características:** Explica su pendiente, por dónde corta a los ejes y cómo se comporta la recta.

## 🧮 Tipos de funciones incluidas
* **Afín (`f(x) = mx + n`):** Cuando `m` y `n` son distintos de 0. Es una recta inclinada que no pasa por el origen.
* **Lineal (`f(x) = mx`):** Cuando `m` es distinto de 0 y `n = 0`. Es una recta inclinada que pasa por el punto (0, 0).
* **Constante (`f(x) = n`):** Cuando `m = 0` y `n` es distinto de 0. Es una recta totalmente horizontal.
* **Nula (`f(x) = 0`):** Cuando `m = 0` y `n = 0`. Es una recta que coincide con el eje X.

## 🛠️ Tecnologías usadas
* **HTML** para la estructura
* **CSS** para los estilos
* **JavaScript** para los números aleatorios y la lógica de las funciones

## 🚀 Cómo probarlo
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en cualquier navegador.
